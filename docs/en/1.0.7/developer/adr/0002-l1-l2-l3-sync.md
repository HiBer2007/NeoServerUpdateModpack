# ADR 0002 · Three-tier sync (L1/L2/L3)

## Status

Accepted (2026-11-27).

## Context

Server content, branch overrides and per-save configs change at different rates and scopes.

## Decision

Split sync into L1 base branch, L2 modpack branch (with parent merge), and L3 per-save serverconfig; apply `sync_policies` at each tier.

## Alternatives

| Option | Pros | Cons |
|---|---|---|
| Keep the previous approach | Less work now | Does not solve the problem |
| Adopt the decision | Solves the problem | Migration and maintenance cost |

## Consequences

- Positive: Clear ownership and safe merges
- Negative:  more moving parts and policy configuration.
