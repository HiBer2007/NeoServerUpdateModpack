# GitIgnoreMarkup usage

## Quick start

```cpp
#include <gitignore_markup.h>
#include <QFile>
#include <QTextStream>

QFile f(".gitignore");
if (f.open(QIODevice::ReadOnly | QIODevice::Text)) {
    const QString text = QString::fromUtf8(f.readAll());
    f.close();

    QVector<GitIgnoreMarkup::Line> lines = GitIgnoreMarkup::parseLines(text);
    for (const auto& line : lines) {
        if (line.kind == GitIgnoreMarkup::LineKind::DisabledRule) {
            // a "temporarily disabled" rule (#! prefix) that plain text parsing cannot tell apart
        }
    }

    QFile out(".gitignore");
    if (out.open(QIODevice::WriteOnly | QIODevice::Truncate | QIODevice::Text)) {
        QTextStream(&out) << GitIgnoreMarkup::serialize(lines);
    }
}
```

## Public API

| API | Signature | Description |
|---|---|---|
| `parseLines` | `QVector<Line> parseLines(const QString& content);` | text -> line list; empty lines dropped; `checked` set for `Rule`/`DisabledRule` |
| `serialize` | `QString serialize(const QVector<Line>& lines);` | line list -> text; unchecked rules written as `#! `; group markers paired |
| `isComment` | `bool isComment(const QString& trimmed);` | whether it is a plain `# ` comment |
| `isLineLabel` | `bool isLineLabel(const QString& trimmed);` | whether it is a `#> ` next-line label |
| `isGroupBegin` | `bool isGroupBegin(const QString& trimmed);` | whether it is a `#{ ` group start |
| `isGroupEnd` | `bool isGroupEnd(const QString& trimmed);` | whether it is a `#}` group end |
| `isDisabledRule` | `bool isDisabledRule(const QString& trimmed);` | whether it is a `#! ` temporarily disabled rule |
| `makeRule` | `Line makeRule(const QString& pattern, bool checked);` | construct a rule line |
| `makeDisabledRule` | `Line makeDisabledRule(const QString& pattern);` | construct an unchecked rule (`#! ` prefix) |
| `makeLineLabel` | `Line makeLineLabel(const QString& text);` | construct a `#> ` label |
| `makeGroupBegin` | `Line makeGroupBegin(const QString& title);` | construct a `#{ ` group start |
| `makeGroupEnd` | `Line makeGroupEnd();` | construct a `#}` group end |
| `makeComment` | `Line makeComment(const QString& text);` | construct a `# ` comment |
| `prefixFor` | `QString prefixFor(LineKind kind);` | returns the standard prefix of that kind |
| `GitIgnoreDialog::GitIgnoreDialog` | `explicit GitIgnoreDialog(const QString& repoRoot, int initialTab = 0, QWidget* parent = nullptr);` | `initialTab` 0 = graphical, 1 = direct editing |
| `GitIgnoreDialog::saved` | `void saved(const QString& absPath);` | emitted after saving (the host runs `git add` / refreshes the panel) |

Fields of `Line`: `LineKind kind`, `QString prefix` (standard prefix without content), `QString text` (content without prefix), `bool checked` (check state of `Rule`/`DisabledRule`).

## Typical usage

### Marker format at a glance

```text
# Plain comment (bound to no line)
#> Server core files        <- next-line label, applies only to the rule right below
#{ Server configuration     <- group begin
server.properties
config/paper-global.yml
#}                          <- group end
#! logs/                    <- ignore temporarily disabled (unchecked, re-check to restore)
*.jar
```

### Checking / unchecking a rule

```cpp
QVector<GitIgnoreMarkup::Line> lines = GitIgnoreMarkup::parseLines(text);

for (auto& line : lines) {
    if (line.kind == GitIgnoreMarkup::LineKind::Rule && line.text == "logs/") {
        line.kind = GitIgnoreMarkup::LineKind::DisabledRule;
        line.checked = false;
        line.prefix = GitIgnoreMarkup::prefixFor(line.kind);   // "#! "
    }
}
const QString serialized = GitIgnoreMarkup::serialize(lines);
```

The reverse (restoring a check) only needs `kind` set back to `Rule` and `checked = true`; serialization removes the `#! ` prefix automatically.

### Adding a labelled group of rules

```cpp
QVector<GitIgnoreMarkup::Line> lines;
lines << GitIgnoreMarkup::makeComment("build output is not committed");
lines << GitIgnoreMarkup::makeGroupBegin("Build output");
lines << GitIgnoreMarkup::makeLineLabel("version file generated by the build");
lines << GitIgnoreMarkup::makeRule("version.json", true);
lines << GitIgnoreMarkup::makeRule("build/", true);
lines << GitIgnoreMarkup::makeGroupEnd();

const QString text = GitIgnoreMarkup::serialize(lines);
```

Serialization guarantees: orphan group-end markers are dropped and an unclosed group at the end gets an automatic `#}`, so repeated round trips stay stable.

### Opening the dialog from the editor

```cpp
auto* dlg = new GitIgnoreMarkup::GitIgnoreDialog(
    QString::fromStdString(repoRoot),  // repository root (the dialog locates <repoRoot>/.gitignore)
    /*initialTab=*/0,
    this);
dlg->setAttribute(Qt::WA_DeleteOnClose);
connect(dlg, &GitIgnoreMarkup::GitIgnoreDialog::saved, this,
        [this](const QString& absPath) {
            // host follow-up: stage the file and refresh the Git panel
            gitPanel_->refresh();
        });
dlg->show();
```

## Notes

- **Do not hand-write the prefix strings**: `#!`/`#>`/`#{`/`#}` prefixes come from `prefixFor` and the `make*` helpers; a hard-coded space difference makes the parser fall back to treating the line as a plain comment.
- **Empty lines are not preserved**: `parseLines` drops them and `serialize` never emits them - do not expect a round trip to keep the user's original blank-line layout.
- **`#> ` binds only to the line immediately below**: inserting a blank line or a group marker in between changes the meaning; after serialization the label still sits directly above its rule line.
- **Group markers must be paired**: an orphan `#}` is dropped; when assembling a `Line` list by hand remember to append `makeGroupEnd()`.
- **`checked` only matters for rule lines**: the `checked` value of comments, labels and group markers is not serialized.
- **Saving is not staging**: the `saved` signal only means the file was written back; `git add`, the commit and the panel refresh belong to the host.
- **The dialog depends on Qt Widgets and HiBerGUILibrary**: a host that only needs plain-text parsing (a CLI) should include `gitignore_markup.h` only and never `gitignore_dialog.h`, otherwise it pulls in the Widgets dependency.
- **Keep highlighting in sync**: `HiBerGUI::GitIgnoreHighlighter` in the editor colors by the same prefix convention, so changing the marker contract means changing both places.
