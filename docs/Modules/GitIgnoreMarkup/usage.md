# GitIgnoreMarkup 使用文档

## 快速开始

根 `CMakeLists.txt` 已 `add_subdirectory(modules/GitIgnoreMarkup)`。宿主 target 链接：

```cmake
target_link_libraries(MyTarget PRIVATE GitIgnoreMarkup)
```

源码侧：

```cpp
#include <gitignore_markup.h>     // 纯逻辑 API
#include <gitignore_dialog.h>     // 仅 GUI 宿主需要（依赖 Qt6::Widgets + HiBerGUILibrary）
```

> 纯逻辑部分仅需 Qt6::Core；`GitIgnoreDialog` 依赖的 Qt6::Widgets 与 HiBerGUILibrary 是 PRIVATE 链接，宿主如需使用 CodeEditor 相关头文件须自行满足 HiBerGUILibrary 链接。

## 公共 API

### 1. `gitignore_markup.h` — 纯逻辑标记系统

**枚举 `LineKind`：**

| 枚举值 | 对应行格式 | 含义 |
|--------|-----------|------|
| `LineKind::Rule` | `<规则>` | 活动规则（勾选态） |
| `LineKind::DisabledRule` | `#! <规则>` | 临时取消忽略的规则（未勾选态，可重新勾选恢复） |
| `LineKind::LineLabel` | `#> <文本>` | 下一行标注 |
| `LineKind::GroupBegin` | `#{ <文本>` | 组开始（首标记） |
| `LineKind::GroupEnd` | `#}` | 组结束（尾标记） |
| `LineKind::Comment` | `# <文本>` | 普通注释（不绑定任何行/组） |

**结构 `Line`：**

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `kind` | `LineKind` | `LineKind::Comment` | 行类型 |
| `prefix` | `QString` | — | 标准前缀（不含内容）：`"# "`、`"#> "`、`"#{ "`、`"#}"`、`"#! "`（Rule 为活动规则无前缀） |
| `text` | `QString` | — | 内容（去前缀；规则行为规则文本） |
| `checked` | `bool` | `true` | `Rule`/`DisabledRule` 勾选态 |

**核心函数：**

| 函数 | 签名 | 说明 |
|------|------|------|
| `parseLines` | `QVector<Line> parseLines(const QString& content)` | 解析文本 → 行列表；空行丢弃；`Rule/DisabledRule` 按行格式置 `checked`（`#! ` → false） |
| `serialize` | `QString serialize(const QVector<Line>& lines)` | 行列表 → 文本；空行不输出；未勾选规则 → `#! `；组首尾成对（孤立组尾丢弃、末尾未闭合自动补 `#}`） |

**行判定（入参为 trimmed 行首）：**

| 函数 | 签名 | 说明 |
|------|------|------|
| `isComment` | `bool isComment(const QString& trimmed)` | `# ` 前缀，或 `#` 开头且非标注/组/临时取消的兜底注释 |
| `isLineLabel` | `bool isLineLabel(const QString& trimmed)` | `#> ` 前缀 |
| `isGroupBegin` | `bool isGroupBegin(const QString& trimmed)` | `#{ ` 前缀 |
| `isGroupEnd` | `bool isGroupEnd(const QString& trimmed)` | `#}` 或 `#} ` 开头 |
| `isDisabledRule` | `bool isDisabledRule(const QString& trimmed)` | `#! ` 前缀 |

**便捷构造：**

| 函数 | 签名 | 说明 |
|------|------|------|
| `makeRule` | `Line makeRule(const QString& pattern, bool checked)` | 活动规则；`checked=false` 序列化时输出 `#! ` |
| `makeDisabledRule` | `Line makeDisabledRule(const QString& pattern)` | 临时取消规则（`checked=false`） |
| `makeLineLabel` | `Line makeLineLabel(const QString& text)` | 下一行标注 |
| `makeGroupBegin` | `Line makeGroupBegin(const QString& title)` | 组开始（首标记） |
| `makeGroupEnd` | `Line makeGroupEnd()` | 组结束（尾标记） |
| `makeComment` | `Line makeComment(const QString& text)` | 普通注释 |

**前缀常量：**

| 函数 | 签名 | 说明 |
|------|------|------|
| `prefixFor` | `QString prefixFor(LineKind kind)` | 标准标记行前缀（供高亮器/UI 判定标签）；`LineKind::Rule` 返回空字符串 |

> 前缀常量实现值：`"# "` / `"#> "` / `"#{ "` / `"#}"` / `"#! "`（`src/gitignore_markup.cpp` 匿名命名空间）。**修改前缀常量须同步 HiBerGUILibrary 的 GitIgnoreHighlighter（自包含复制同款常量）**。

### 2. `gitignore_dialog.h` — 编辑 GUI

**`class GitIgnoreDialog : public QDialog`**（Q_OBJECT，命名空间 `GitIgnoreMarkup`）：

| 成员 | 签名 | 说明 |
|------|------|------|
| 构造函数 | `explicit GitIgnoreDialog(const QString& repoRoot, int initialTab = 0, QWidget* parent = nullptr)` | `repoRoot` = 仓库根目录（读写 `<repoRoot>/.gitignore`）；`initialTab`：0=图形化编辑，1=直接编辑 |
| 析构 | `~GitIgnoreDialog() override` | 释放内部 `GitIgnoreHighlighter`（CodeEditor 生命周期由其宿主管理） |
| 信号 `saved` | `void saved(const QString& absPath)` | 任一 tab 保存成功后发出，`absPath` = `<repoRoot>/.gitignore`；宿主负责 `git add` 与 Git 面板刷新 |

界面能力（图形化页）：规则勾选/取消勾选（保存为 `#!` 临时取消、可恢复）、手输 + 通配符快捷插入（`**`/`*`/`?`/`[ab]`/`!`/`/`/`\#`/`\!`，按钮 tooltip 说明用途）、常用预设、自动总结仓库建议（勾选添加）、标注下一行（`#>`）、下一组标注（`#{...` / `#}`）、删除所选、上移/下移。直接编辑页：HiBerGUI CodeEditor（Qt 版）+ GitIgnoreHighlighter（Ctrl+S 保存）。

## 典型用法

### 1. 解析 → 增删规则 → 序列化往返

```cpp
#include <gitignore_markup.h>

// content 为磁盘读出的 .gitignore 文本
auto lines = GitIgnoreMarkup::parseLines(content);

// 增加规则与注释
lines.append(GitIgnoreMarkup::makeRule("build/", true));
lines.append(GitIgnoreMarkup::makeComment("generated by NSUM"));

QString out = GitIgnoreMarkup::serialize(lines);   // out 可直接写回磁盘（UTF-8）
```

往返示例：输入 `"*.log\n#! temp/\n"` → 解析为 2 行（Rule `*.log`、DisabledRule `temp/`）→ `serialize` 原样还原（勾选态保持）。

### 2. 取消 / 恢复规则勾选

```cpp
auto lines = GitIgnoreMarkup::parseLines(content);
for (auto& l : lines) {
    if (l.kind == GitIgnoreMarkup::LineKind::Rule
        && l.text == QStringLiteral("*.log")) {
        l.checked = false;            // 序列化输出 "#! *.log"；改回 true 则恢复活动规则
    }
}
QString out = GitIgnoreMarkup::serialize(lines);
```

### 3. 分组标注

```cpp
auto lines = GitIgnoreMarkup::parseLines(content);
lines.append(GitIgnoreMarkup::makeGroupBegin(QStringLiteral("Build Outputs")));
lines.append(GitIgnoreMarkup::makeRule("build/", true));
lines.append(GitIgnoreMarkup::makeRule("dist/", true));
lines.append(GitIgnoreMarkup::makeGroupEnd());

QString out = GitIgnoreMarkup::serialize(lines);
// out == "#{ Build Outputs\nbuild/\ndist/\n#}\n"
// 若末尾漏写 makeGroupEnd()，serialize 自动补 "#}" 保证首尾成对
```

### 4. 行判定（供高亮器 / UI 分类）

```cpp
const QString t = rawLine.trimmed();
if (GitIgnoreMarkup::isDisabledRule(t))      // "#! ...": 临时取消规则
    ;  // ...
else if (GitIgnoreMarkup::isLineLabel(t))    // "#> ...": 下一行标注
    ;
else if (GitIgnoreMarkup::isGroupBegin(t))   // "#{ ...": 组开始
    ;
else if (GitIgnoreMarkup::isGroupEnd(t))     // "#}" 或 "#} ...": 组结束
    ;
else if (GitIgnoreMarkup::isComment(t))      // "# ..." 或未识别 # 前缀: 普通注释
    ;
else if (!t.isEmpty())                       // 其余非空行: 活动规则
    ;
// 注意: 判定入参须为 trimmed 行首; 数字前缀匹配由 prefixFor/实现常量保证一致
```

### 5. GitIgnoreDialog 使用（宿主集成）

```cpp
#include <gitignore_dialog.h>

// repoDir = 仓库根目录（如 workspace 分支目录）
GitIgnoreMarkup::GitIgnoreDialog dlg(repoDir, 0, this);   // 0=图形化编辑, 1=直接编辑
connect(&dlg, &GitIgnoreMarkup::GitIgnoreDialog::saved, this,
    [this](const QString& absPath) {
        gitAddPaths({ absPath });          // 宿主负责 git add（NeoWorkspaceEditor 实现）
        if (gitPanel_) gitPanel_->refresh();
        // 实际实现使用中文 GUI 文案（源码按 \uXXXX 转义，见 editor_window.cpp:2781）
        statusBar()->showMessage(QStringLiteral("已保存并跟踪: %1").arg(absPath), 5000);
    });
dlg.exec();
```

## 注意事项

- **判定函数入参为 trimmed 行首**：`isXxx` 系列不自行 trim，调用方须先 `raw.trimmed()`（`parseLines` 内部已处理）。
- **`isComment` 兜底语义**：以 `#` 开头且非 line-label / group-begin / group-end / disabled-rule 的行一律判为普通注释。
- **`prefixFor(LineKind::Rule)` 返回空字符串**：活动规则无前缀，序列化直接输出规则文本。
- **序列化约定**：① 未勾选规则与 `DisabledRule` 统一按 `checked` 输出（勾选→裸规则，未勾选→`#! ` 前缀）；② `GroupEnd` 在组深度为 0 时被丢弃（孤立组尾）；③ 末尾未闭合组自动补 `#}`（成对保证）。
- **解析丢弃空行**；注释 `text` 去掉 `"# "` 前缀后保存。
- **GUI 显示与磁盘格式不同**：图形化列表组内行 4 空格缩进、组背景色块 `#1e3a3f` 边界隔离；组首显示 `▶ `（`kGroupBeginMark`，U+25B6）替换 `#{ ` 标记文本；另行标注显示 `>>> `（橙）；组尾由 `GitIgnoreListDelegate`（QStyledItemDelegate 子类）渲染为水平分割线（`#3f6a70`，sizeHint 14px）且文本置空。序列化前经 `stripDisplayPrefix` 剥离组缩进/`▶`/`>>>` 还原纯内容——**磁盘格式始终是标准行格式，不要手工绕开**。
- **循环依赖铁律**：HiBerGUILibrary **不得**链接 GitIgnoreMarkup；`GitIgnoreHighlighter`（`gitignore_highlighter.cpp`）自包含前缀判定、复制同款前缀常量、不 include `gitignore_markup.h`。**修改本模块前缀常量后必须同步 HiBerGUILibrary 高亮器**。
- **解析/序列化一律走模块 interface**：编辑类代码勿手写行分类逻辑（`gitignore_dialog.cpp` 已入模块直用 `parseLines/serialize`）；新增 .gitignore 行处理需求应复用本模块 API。
- **GitIgnoreDialog 不负责 git add**：保存即写盘 `<repoRoot>/.gitignore`（UTF-8）+ `emit saved(absPath)`；宿主须监听 `saved` 执行 `git addPaths` + Git 面板刷新（见 NeoWorkspaceEditor `EditorWindow::openGitIgnoreDialog`，editor_window.cpp:2770）。
- **初始 tab 约定**：`initialTab` 0=图形化编辑、1=直接编辑（EditorWindow「忽略文件 (.gitignore)」子菜单两入口分别传 0/1）。
- **对话框暗色适配**：CodeEditor 根据 `palette().color(QPalette::Window).lightness() < 128` 自动切换暗色模式。
