# 故障排查

本文收集 NSUM 构建工具（GUI 向导 + CLI）的常见问题与排查方法。

## 构建失败

### 仓库相关

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 克隆/拉取超时 | 网络不通、代理未配置、仓库过大 | 检查网络；改用本地路径仓库 |
| SSH 认证失败 | 未配置 SSH 密钥 | 配置 `~/.ssh` 密钥并添加到托管平台 |
| 仓库不是 Git 仓库 | 路径错误/目录无 `.git` | 确认路径；用 `exec verify-repo --repo <path>` 校验 |
| `workspace.json` 无效 | 数据格式错误 | 用编辑器打开修复；`info workspace --repo <path>` 查看解析错误 |

### 配置解析相关

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 解析器缺失 | `parsers/` 插件不完整 | 检查部署目录含 5 个解析器 DLL + meta |
| 文件无法解析 | 格式损坏 | 用编辑器修正对应配置文件 |

### 指针下载相关

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| Modrinth 查询失败 | API 不可达 | 检查网络；稍后重试 |
| 哈希校验不匹配 | 上游文件变更 | 重新生成指针；清空 `.cache` 后重试 |
| 无匹配解析器 | `pointers/` 缺失/指针 resolver 拼写错误 | 检查部署目录；用 `exec resolve-pointer <file.pointer>` 单测 |

### 输出相关

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 写入被拒绝 | 目录只读/权限不足/磁盘满 | 更换导出目录；检查磁盘空间 |
| 文件名非法 | 含 `\ / : * ? " < > |` | 修改整合包名称 |

## 警告处理

构建完成但带警告时，完成页显示警告数量，可点「展开警告详情」查看逐条警告；
也可点「打开帮助文档」阅读本文档。常见警告：

- 指针文件无解析器可用（构建跳过该文件）
- 同步策略未匹配的路径（按默认策略处理）
- 继承链中的文件被覆盖/删除标记冲突

## 崩溃与崩溃报告

- 程序崩溃会自动生成报告到 `crash-report/<日期时间>/`（`.dmp`/`.trace`/`.meta`）。
- 用 `CrashTracker.exe <报告>` 解析转储输出完整报告（支持 `--cli` 模式输出到终端）。
- 反馈问题时请附上整个 `crash-report/<时间戳>/` 目录。

## 内置 Git 更新

`exec git-update` 可安装/更新内置 MinGit 并写入安装配置：

```
NeoServerUpdateModpack.exe exec git-update
```

- system git 模式下该命令提示无操作（exit 1，属预期）。
- 已安装布局（Installer 安装）写在安装根 `install.conf`；开发布局写在部署目录上级。

## CLI 模式错误

CLI 相关报错、退出码与参数搭配陷阱详见 [CLI 错误手册](../CLI/CLI-errors.md)。

| 退出码 | 含义 |
|--------|------|
| 0 | 成功 |
| 1 | 运行期错误 |
| 2 | 参数用法错误 |

## 帮助文档打不开

「帮助文档」标签/按钮点击后提示「无法打开帮助」：

- 部署目录缺少 `PowerHelper.exe`（随部署分发的独立阅读器）。
- 目标文档不存在时程序会自动回退打开 `docs/` 文档组；若仍失败说明部署不完整。

## 术语速查

| 术语 | 说明 |
|------|------|
| 指针文件 | 缺失文件占位符（`<sha256>.pointer`），构建时按哈希下载 |
| 指针缓存 | 已下载文件按哈希缓存，构建对比哈希秒级完成 |
| 同步策略 | 文件/文件夹随构建的同步规则（默认/增量/镜像/跳过） |
| 分支继承 | 整合包分支继承父分支文件，构建时自动合并 |
